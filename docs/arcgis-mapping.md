# מיפוי ArcGIS → WordPress

נסרק 15/10/2026 מהדשבורד `c94e67e1a01347f19d5bc677bcdf0d99` (log-pm.maps.arcgis.com, פרטי).

## המקור

שלוש ה"תצוגות" בדשבורד (`All_Plans_View`, `Status_View`, `PM_View`) הן אותה שכבה: **`blue_lines_main`** — פוליגונים של הקו הכחול של כל תכנית, ב-`services-eu1.arcgis.com/lDcqcwePoeu47saG`.

- **99 רשומות**, לכולן גיאומטריה (פוליגון, 34–1,000 נקודות). היקף: ישראל כולה (29.5°–33.1°N).
- 17 שדות. השמות בעברית עם קו תחתון. ערכי הדומיינים נשמרים כקודים (`"02"`), התוויות רק בהגדרת השכבה.
- **20 רשומות חסרות שם / מספר תכנית / יח"ד.** צריך ניקוי לפני פרסום (ממילא האתר מציג רק "מאושר לפרסום").
- סכום יח"ד: 110,813 (הדשבורד מציג 104k אחרי סינון סטטוס).

### מה אין ב-ArcGIS (נשאר ידני בוורדפרס)

## ייבוא

הקוד: `log-core/inc/import.php`. המסך: **כלים → ייבוא מ-ArcGIS** (דורש `manage_options`).

### איך מריצים

1. ב-ArcGIS Online פותחים את פריט השכבה `blue_lines_main` → Export → **GeoJSON**. הקובץ יוצא ב-WGS84 עם הקודים (לא התוויות); גם קובץ עם תוויות או ב-Web Mercator מתקבל.
2. wp-admin → כלים → ייבוא מ-ArcGIS → בוחרים את הקובץ (עד 20MB) ומריצים **בהרצה יבשה** (ברירת המחדל). הטבלה מראה לכל רשומה מה היה קורה: נוצרת / מתעדכנת / מדולגת, ולמה.
3. מסירים את הסימון "הרצה יבשה" ומריצים שוב. בסוף מוצג סיכום ומטמון המפה (`/wp-json/log/v1/map`, `/stats`) מתנקה.
4. עוברים על הטיוטות החדשות ב"פרויקטים", משלימים תחום, סיפור ומדיה, ומסמנים "מאושר לפרסום" + פרסום. רק אז התכנית עולה לאתר ולמפה.

### מה הייבוא עושה

- **זיהוי:** `arcgis_id` = `OBJECTID`; אם אין OBJECTID, לפי `plan_number`. תכנית בלי שם מדולגת.
- **חדש:** טיוטה, `approved=0`. **קיים:** מעדכן רק שם התכנית ושדות ArcGIS (עיר, מספר תכנית, יח"ד, אבן דרך, סטטוס, סוג תכנית, מוסד, מחוז, לקוח, גיאומטריה). לא נוגע בסיפור, מדיה, אבני דרך עם שנים, שותפים, "נבחר", "מאושר לפרסום", או בסטטוס הפוסט.
- **לקוח:** `מזמין_העבודה` → פוסט `log_client` לפי שם (נוצר אם חסר, עם `body_type`). טבלת הקודים ב-`log_import_client_codes()` מכילה רק את מה שידוע (99, 14, 2, 3, 18); קוד שלא בטבלה מדווח בהערות והלקוח לא משויך. להשלמת 19 הקודים: להעתיק את התוויות מהגדרת השכבה לטבלה (או לפילטר `log_arcgis_client_labels`).
- **עיר:** שדה `city` + מונח `log_city`. "לא רלוונטי" → ריק.
- **תחום (רק ביצירה):** מזמין 99 → התחדשות עירונית; `סוג_תכנית` מתארית → תכניות מתאר. בייבוא חוזר התחום לא נוגע, הוא של העורכים.
- **רשימת הפרויקטים** ב-wp-admin מקבלת עמודת ArcGIS (OBJECTID + סטטוס, ניתנת למיון) כדי להבדיל תכניות מיובאות מידניות.
- **נגזרות:** אחרי כתיבת השדות נקרא `log_project_recompute_derived()` (שלב מאבן הדרך, מדרגת היקף), אותה פונקציה שרצה בשמירה ידנית.
- **גיאומטריה:** צנטרואיד משוקלל-שטח → `lat`/`lng`; Douglas-Peucker ב-0.00005° → `boundary` (GeoJSON, 6 ספרות); שטח גאודזי (נוסחת Chamberlain–Duquette על כדור) ÷ 1000 → `dunam`, מעוגל. `Shape__Area` לא בשימוש.
